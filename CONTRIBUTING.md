# Contributing to Awesome World Models

Thank you for your interest in contributing! This project aims to maintain the most comprehensive and up-to-date collection of World Model research.

## How to Contribute

### Adding a New Paper

1. Fork this repository
2. Add your paper to the appropriate section in `README.md`
3. Follow the table format:

```
| # | Title | arXiv | GitHub | Year | Accepted by | Keywords |
```

4. Make sure to include:
   - Full paper title
   - arXiv link (or `/` if not available)
   - GitHub/code link (or `/` if not available)
   - Publication year
   - Venue (e.g., "ICLR 26 poster", "NeurIPS 25 Oral", or "arXiv preprint")
   - 2-3 keywords

5. Submit a Pull Request with a clear description

### Suggesting a New Category

If you think a new category should be added, please open an issue first to discuss.

### Fixing Errors

If you find incorrect information (wrong venue, broken links, etc.), please submit a PR with the fix.

## Guidelines

- Papers should be related to World Models (broadly defined)
- Include only papers with publicly available manuscripts (arXiv, conference proceedings, etc.)
- Keep entries sorted chronologically within each section (newest first or by relevance)
- Use consistent formatting

## Code of Conduct

Please be respectful and constructive in all interactions.
